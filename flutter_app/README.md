# Babel Jewelry Flutter

هذا المجلد هو Scaffold أولي لتحويل تطبيق `مجوهرات بابل` من React/Capacitor إلى Flutter بدون تغيير قاعدة البيانات الحالية.

## الحالة الحالية

- الخلفية الحالية `Supabase` ما زالت هي المصدر الرسمي للبيانات.
- لوحة الإدارة لم تُنقل بعد إلى Flutter.
- الشاشات الحالية هنا تمثل هيكل الهجرة فقط، وليست بديلاً كاملاً بعد.

## الهدف من هذا المجلد

- إنشاء طبقة Flutter مستقلة داخل نفس المستودع.
- تجهيز Router وهيكل Features واضح.
- تهيئة Supabase عبر `dart-define` بدلاً من تضمين أسرار داخل الكود.
- البدء بنقل الوحدات بالتدريج من التطبيق الحالي.

## التشغيل

1. اجلب الحزم:

```bash
flutter pub get
```

2. شغّل التطبيق مع متغيرات Supabase:

```bash
flutter run ^
  --dart-define=SUPABASE_URL=YOUR_SUPABASE_URL ^
  --dart-define=SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

## ما الذي لم نغيّره عمداً؟

- جداول Supabase
- سياسات RLS
- Storage bucket
- RPCs
- Edge Function الخاصة بأسعار الذهب

## مسار الهجرة القادم

1. نقل المصادقة.
2. نقل الكتالوج والمفضلة.
3. نقل أسعار الذهب.
4. نقل الطلبات والاستوديو الذكي.
5. تقرير قرار منفصل بشأن لوحة الإدارة.
